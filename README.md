# 《杀戮尖塔 2》（Slay the Spire 2）对局复盘与决策记录库

本仓库记录每一局《杀戮尖塔 2》的完整爬塔决策过程、真实心理博弈与赛后复盘。

## 核心准则
- **真实人类视角，严禁作弊**：不使用求解器、不开天眼、不窥探未来未翻开牌序与随机掉落。允许基于已知地图全局布局、已知怪物池与自身牌组结构进行的正常人类规划与计算。
- **逐层全操作与决策理由**：记录每一层（Neow 开局、普通/精英/Boss 战斗、选牌抓/跳、商店购物与删牌、事件取舍、火堆休息/锻造、药水保留与使用）的详细动机。
- **全官方简体中文牌名 & 完整三幕分支地图**：所有卡牌、遗物、药水、事件、敌人均采用官方简体中文命名；每幕均提供含**已选路线**与**未选分支路径**的完整分支拓扑图（Mermaid `flowchart TD`）。
- **回合均伤害（DPT）与承伤数学复盘**：重点战斗逐回合记录出牌链并核算回合均伤害与输出效率。
